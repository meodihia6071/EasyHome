# Vietnam administrative divisions data

`vietnam-administrative-divisions.json` contains the 34 province/city and 3,321 commune/ward names from Open Admin Data's post-2025 hierarchy dataset.

- Source: https://github.com/open-admin-data/vietnam-administrative-divisions
- License: CC-BY-4.0
- Snapshot retrieved: 2026-11-16
- The application stores ward/commune names in the legacy `district` property field for backward compatibility; the UI labels it with the current level.
- Street suggestions come from active listing addresses; users may still enter a street not in the suggestions.
